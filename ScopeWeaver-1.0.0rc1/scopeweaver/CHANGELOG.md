# Changelog

## 1.0.0rc1 — 2026-10-22

- Introduced a scope-enforced async transport with explicit infrastructure endpoints,
  connection pinning, global limits, audit logs and operator cancellation.
- Added DNS/WHOIS/HTTP/TLS reconnaissance, bounded TCP inventory and safe web audits.
- Added offline AD snapshot checks and synthetic password/policy analysis.
- Added structured JSON, escaped HTML and Markdown reports with reproducible CLI examples.
- Added local-service integration fixtures, CLI tests, strict type checking and CI configuration.

This is a release candidate. Cross-platform CI execution and manual operating-system checks
remain publication-time gates; see [RELEASING.md](docs/RELEASING.md).
